# ⚡ Prácticas de Circuitos

Repositorio de prácticas de Circuitos con cuadernos de Jupyter y hojas de cálculo de apoyo, organizado para trabajar práctica por práctica de forma clara y reproducible.

---

### ✨ Qué incluye
- ✔️ Guiones de las prácticas  en la carpeta Guiones como material de referencia.
- 📓 Un cuaderno de Jupyter por práctica con el flujo de trabajo de la actividad.
- 📊 Plantillas Excel vacías para registrar datos y resultados dentro de Guiones/Excel y en cada práctica así como las completadas por nosotros.

---

### 📂 Estructura
- Guiones/: guiones de las prácticas de referencia.
- Guiones/Excel/: hojas de cálculo vacías sin modificar para completar durante la sesión.
- Carpeta por práctica: cuaderno .ipynb y archivo .xlsx con los datos de esa práctica.

---

### 🧰 Requisitos
- Entorno con Jupyter Notebook o JupyterLab para ejecutar los cuadernos .ipynb.
- Python para el pequeño porcentaje de utilidades auxiliares del repositorio.

---

### 🚀 Puesta en marcha
1. Clonar el repositorio localmente con la herramienta preferida de Git.
2. Abrir Jupyter (Notebook o Lab) en la carpeta del proyecto y cargar la práctica correspondiente.
3. Completar la plantilla Excel asociada y seguir los pasos del cuaderno para registrar mediciones y cálculos.

---

### ✅ Buenas prácticas sugeridas
- Mantener las plantillas Excel originales de Guiones/Excel sin modificar y trabajar sobre copias por sesión o por grupo.
- Guardar resultados y versiones de cuadernos dentro de la carpeta de cada práctica para trazabilidad.
- Añadir, si se desea, un archivo de entorno o dependencias para reforzar la reproducibilidad en distintas máquinas.

---

### 📊 Estado del proyecto
- Sin releases ni paquetes publicados; el contenido se usa directamente desde la rama principal .
- Lenguajes: Jupyter Notebook ~99.7% y Python ~0.3% según el desglose del repositorio.
